# 3laba_3sem — Тестирование структур данных

Лабораторная №3, 3 семестр. Набор тестов для структур из 1-й лабы + эксперименты.

## Что внутри
- `Cpp/` — Makefile, `include/`, `tests/`, `coverage/`, тестовые данные `test_*.txt` (array, list, stack, queue, hashtable, tree)
- `num1/build`, `Gо/` — дополнительные эксперименты

## Стек
C++, Makefile, файловые тесты

## Запуск
```bash
cd Cpp && make
./build/tests
```

## Что изучено
Модульное тестирование своих структур, сравнение поведения на граничных данных.
