# Тестирование и сериализация структур данных

Лабораторная №3: тесты пользовательских структур данных на C++ и дополнительные эксперименты на Go. Сохранены входные данные и варианты сериализации.

## Структура

- [Cpp/include](Cpp/include/) — реализации структур.
- [Cpp/tests](Cpp/tests/) — тесты массива, списков, стека, очереди, хеш-таблицы и дерева.
- [Cpp/Makefile](Cpp/Makefile) — сборка тестов и отчёта покрытия.
- [Gо](G%D0%BE/) — эксперименты с очередью и сериализацией на Go.

В имени каталога `Gо` последняя буква кириллическая.

## C++: сборка тестов

Нужны компилятор C++, Make и GoogleTest, доступный линковщику.

```bash
cd Cpp
make cpp_test
for test in build/*.out; do "$test" || exit 1; done
```

`make cpp_coverage` дополнительно использует `gcovr`. Цель покрытия в исходном Makefile продолжает работу после падения теста, поэтому результат тестов лучше проверять отдельной командой выше.

## Go: тесты очереди

```bash
cd "Gо/tests"
go test ./...
```

## Статус проверки

Команды составлены по текущему Makefile и Go-модулю. Полный набор тестов при оформлении репозитория не запускался.
